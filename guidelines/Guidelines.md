# ELECTRICSUNTANNING — Brand & Design Guidelines

## Stance
Local, chill, a little eccentric. A neighborhood tanning studio in Caldwell, Idaho with a neon sign in the window — deep greens, glowing lime, handwritten notes taped to the counter. Human first, polished second.

## Color Palette
| Token | Value | Use |
|---|---|---|
| Background | `#F2F7E6` | Pale lime-cream page ground |
| Foreground | `#06231B` | Deep pine green text |
| Primary | `#3E9C14` | Vivid green — primary actions |
| Accent | `#9BE81E` | Neon lime — highlights |
| Neon pop | `#BFF747` | Neon signage glow — hero words, marquee, badges |
| Muted fg | `#8FAE94` | Sage — secondary text |
| Dark canvas | `#06231B` | Hero, footer, and admin sections |

Neon glow (text-shadow / box-shadow in lime) is for key headings, the logo, and CTAs only — signage, not cyberpunk.

## Typography
- **Display**: Shrikhand — chunky headlines with character
- **Handwritten**: Caveat — little annotations, stickers, asides
- **Body / UI**: DM Sans 300–500 — labels, body, nav
- **Data**: DM Mono — admin IDs, timestamps

## Pages
1. **Hero** — full-bleed image, chunky display headline with neon glow, marquee strip, sticker badges
2. **Services** — 2-col grid with photo + features + price + CTA, cards tilted a degree off-straight
3. **Booking** — 3-step wizard: service → date/time → details → confirmation
4. **About** — story, values grid, team
5. **News** — Instagram-style photo grid with modal
6. **Contact** — form + info + hours
7. **Admin** — deep-green sidebar dashboard: KPIs, revenue chart, pie chart, bookings table

## Voice
Short, friendly, local. Talk like the person at the front desk, not a brochure. Second person. No clinical language, no luxury-boutique clichés.
